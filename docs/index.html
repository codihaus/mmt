▾ FEATURES

The parts you use every day

Everything here works against a normal Mattermost server with a personal access token. No plugin, no server changes.

Alt+UCtrl+T

Your sidebar, exactly as the App/Web has it

Custom categories, favorites, DMs, unread counts and mention badges come straight from your account, the same as in the desktop app and on the web. Alt+U (or the button on top) hides everything without new messages, like the unread filter in the app and on the web.

Ctrl+L/lockTouch ID

Lock it like a phone

Touch ID or a passcode, separate from your Mattermost login. Ctrl+L or /lock locks it on the spot, idle time locks it later, and while it is locked notifications only say "New message". The passcode is kept as a hash in the keychain.

/uploadCtrl+V

A file browser in the chat box

/upload opens a small file manager: newest files first, a preview on the right, and typing searches the folder and everything below it. Tab picks several. Ctrl+V pastes a screenshot, and dropping a file on the window attaches it.

e+:thumbsup:

Reactions without the mouse

Select a message and press e: pick one of eight with a number key, or type to search every emoji the server knows. Picking one you already used removes it. +:eyes: reacts to the latest message, the same shortcut as the app and the web.

↑EnterTab

Threads open beside the channel

Press ↑ to pick a message and Enter to open its thread, or click it twice. The thread gets its own panel and its own input, and Tab moves between them.

mmt background on

Notifications after you quit

A small background agent stays connected and shows a macOS notification for mentions, DMs and incoming calls. Click one and mmt opens on that channel. While a window is open the agent stays quiet, so nothing pings twice.

▾ MORE

And the rest of a working day

Jump anywhere with Ctrl+K

Finds channels, people and channels you haven't joined. It ignores accents, so co hoi finds Cơ hội.

Bot cards you can actually read

CI results, alerts and bounty posters from integrations keep their colored bar, title, fields and footer. Buttons open the message on the web.

Images inline on iTerm2

Pictures render in the conversation. o opens attachments in a private temp folder, and only safe file types open directly.

Run a command, share the output

!git log -3 runs on your machine. The output stays local unless you press Enter, which posts it as a code block.

Admin chores as small forms

/channel new, /add, /bot new, /token new ask one thing at a time and suggest people as you type. New tokens go to the clipboard, never into the chat.

Calls go to the browser

A terminal can't do audio. Calls show up as cards, and /call or a click joins the call directly in your browser.

  • Cmd keys work on iTerm2 and Ghostty: mmt reopens itself there with Cmd+K, Cmd+V and Shift+Enter mapped.
  • Safe to read anything. Control characters are stripped, so a message can't change your title bar or write to your clipboard.
  • Stays out of tmux's way. Inside tmux, screen, zellij or SSH it runs right where you are.
  • English and Vietnamese interface, following your LANG or the config.
  • Server commands still work. Anything mmt doesn't know, like /away or /header, goes to the server.
  • macOS, Linux and Windows. One universal Mac binary; Windows is an early preview.

▾ INSTALL

Install it in a minute

Download the archive for your machine from the releases page, then run its installer. Nothing else to install.

tar -xzf mmt-macos-*.tar.gz && sh mmt-macos/install.sh
mmt login && mmt

One binary for Apple silicon and Intel, copied to ~/.local/bin. It isn't notarized yet, which is why it installs from the terminal.

tar -xzf mmt-linux-amd64-*.tar.gz && sh mmt-linux-amd64/install.sh
mmt login && mmt

amd64 and arm64 builds. Uses xdg-open, wl-copy or xclip, and notify-send when they're installed.

powershell -ExecutionPolicy Bypass -File .\mmt-windows-amd64\install.ps1

An early preview: chat, threads and commands work; image paste, inline images and the background agent are not there yet. Use Windows Terminal.

go install github.com/codihaus/mmt@latest

Needs Go 1.26.7 or newer.
